# README.md 更新タイミング

PR を作成する直前に README.md を最新化する。

**Why:** README は外部向けのエントリポイントであり、コード変更と同期が取れていない状態でマージされると、スクリプト一覧・使い方の記述が実態と乖離する。

**How to apply:**

- スクリプトの追加・削除・機能変更を行ったら、PR 作成直前に README.md を見直す。
- 追加されたスクリプトはテーブルや説明欄に反映する。
- 削除・リネームされたスクリプトはその記述を除去する。
- PR 作成コマンド（`gh pr create`）を実行する前に README.md の差分を確認する。
